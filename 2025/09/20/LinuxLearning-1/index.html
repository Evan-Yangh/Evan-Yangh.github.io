Linux 学习笔记1(浅浅记录一下学习的皮毛)

Linux Note

文件层级

flowchart TD
/ --- home
/ --- bin
/ --- dev
/ --- boot
/ --- ...
文件夹 content
/boot Linux系统启动文件，包括镜像文件等
/dev connected devices, Linux handles devices as same as files
/home belong to each user
/root 管理员目录
/etc 系统管理文件

文件与目录管理

ls [-a -l -h ] :

-l : 列表展示，更多信息

-h : 需与-l组合使用，展示储存大小

-a -l -h 何以组合使用，e.g. -al -la…

pwd

(print work directory)

展示工作目录

cd

相对路径： . :当前目录 .. ：上级目录 ~: home

mkdir [-p -m]

-p 连续创建多层文件夹
-m 强制设置文件夹权限

touch [path]

创建文件

cp [-r] 文件(夹) 文件(夹)

复制

-r 复制目录使用

which

查找命令地址

Linux命令是可执行的binary文件

find

find 起始路径 -name “file” ——按名称查找

find 起始路径 -size +/-n (k/M/G) ——按照文件大小查找

echo [-e] [message]

相当于print，输出message.

message可以是字符，也可以是命令
-e: 支持转义字符

当 message 较复杂（含有空格、\时，必须加上“ “）
建议都加上

>, >>

重定向符

> : 用左边输出的内容覆盖右边的文件

>> : 将左边输出的内容追加到右边的文件中

tail [-f -num] file

output the tail of the file

-num: number of output rows, default is 10

-f: choose to follow the change of the file，当文件末尾追加了内容，终端会持续输出

grep

在文件中查找关键词，-n选择输出行号

wc

-l: 行数
-w: 单词数
-c: 字节数
-m: 字符数

默认输出 -l -w -c

管道符 |

将左边的输出作为右边的输入

rm

加上 -r时可以删除目录，如rm -r dir/list，删除list目录

-ri 询问删除的每一个

-rI 每三个询问一次

用户与权限

Linux权限单元为用户组和用户

root用户具有最大权限

切换用户：

sudo

临时获得root权限，需为普通用户赋予权限：

[root] visudo

增加配置，sudo 可以不用密码

用户与用户组管理

1、用户组： groupadd groupdel

2、用户：

getent 查看数据库信息

这里也可用于查看用户(组)
getent passwd [user] 查看所有（某个）用户信息

getent group 查看所有用户组

getent hosts …

文件权限信息：

文件权限信息由0~9位组成
第0位：d: 文件夹 -: 文件 l: 软连接

13: 所属用户权限 46：用户组权限 7~9：其他用户权限

r: 可读 w: 可写 x:可以执行

chmod

修改权限

chmod [-R] 权限 文件(夹)

-R：对文件夹内全部文件进行修改操作，否则只改文件夹权限

1、直接指明权限

2、用数字表示权限

每一组权限有三位，一共三组，我们可以用二进制

r w x : –x:1 -w-:2 -wx: 3 … rwx:7

所以上面命令可表示为

chown

chown [-R] [user] : [group] 文件(夹) 修改文件所属用户、用户组

只能root执行

压缩与解压

linux常用操作格式 :

.tar: 简单封装，体积不压缩

.gz: 体积压缩

-c: 压缩，-x： 解压
-v：显示进度，-f 要创建的文件/解压的文件，-z：gzip模式，gz压缩选择，-c：解压目的地

-z只能在开头，-f只能在最后
